Frappe Server Script (Automated Webhook Trigger)

Paste into Frappe Desk > Server Script to automatically call InsureVoice AI when a Lead is saved.

# In Frappe Desk > Server Script (DocType Event on 'CRM Lead' > After Save):
import frappe
from frappe.integrations.utils import make_post_request

if doc.status in ["Follow Up Needed", "Renewal Due"]:
    make_post_request(
        url="http://localhost:3030/api/webhooks/frappe-lead",
        data={
            "event": "LEAD_FOLLOW_UP_TRIGGERED",
            "name": doc.name,
            "lead_name": doc.lead_name or doc.name,
            "mobile_no": doc.mobile_no or doc.phone,
            "custom_insurance_type": doc.get("custom_insurance_type") or "Comprehensive Motor Insurance",
            "custom_expiry_date": str(doc.get("custom_expiry_date")),
            "custom_premium_amount": doc.get("custom_premium_amount") or "$840.00"
        },
        headers={"Content-Type": "application/json"}
    )
